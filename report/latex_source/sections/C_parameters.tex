\chapter{Vehicle Parameter Tables}
\label{app:param}

The physical parameters used in the models and the simulation study are listed
here. The hexacopter values are those of a published multirotor model; the
fixed-wing values are the Aerosonde first-edition parameters of
Beard and McLain \cite{beard2012small}.
